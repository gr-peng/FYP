项目已经具备两个可用基础：有审计记录的单资产内生市场；以及人类示例相对 vanilla/persona 改善聚合风险选择拟合的证据。主要研究缺口是：校准是否提供超出简单统计基线的有效行为信息，是否迁移到有持仓、私有信号和反馈的金融决策，以及这些微观改变是否改善市场层面的实证拟合。

近期重点应放在这条证据链，控制资产、事件和模型数量。市场成交更多、价格波动更大，均不能单独定义为“更真实”。

**本次新发现：应先完成的离线核对**

1. **简单概率基线尚未进入原比较。** 本次仅在已经使用的 300 题 development 上补算，未用这些基线选择旧 final 的方法：

| Development 方法 | MAE | 解释 |
|---|---:|---|
| B0 | 0.30209 | 原实验结果 |
| B2 matched K=4 | 0.25463 | 原实验结果 |
| 恒定概率 0.5 | 0.18053 | 每道题预测 B 的比例为 0.5；没有题目区分能力 |
| calibration pool 平均率 | 0.18055 | 预测率为 0.499773，由 600 题 pool 计算 |
| matched K=4 示例率均值 | 0.18237 | 同一检索规则直接平均四个 calibration 标签，不调用 LLM；沿用旧规则的歧义题缺陷 |
| 每题独立抛硬币 10 次 | 0.21641 | 二项分布精确求出的预期 MAE，并非一次实际模拟或置信区间 |

恒定概率与有限次采样所得比例不是同一种估计器，因此同时报告 10 次公平随机选择的解析期望。计算为对 k=0…10 加权求和：`C(10,k) / 2^10 * abs(k/10 - human_rate)`，再对 item 平均。

这些开发集结果不否定 B2 相对 B0 的改善，也不证明随机 agent 能模拟真人。但它们表明：当前误差仍较大，主指标容易奖励向中间概率收缩，尚不能声称 B2 是强行为预测器。新实验需要同时检验概率误差、题目间区分能力和条件行为反应。可在 development 探索 B0/B2 的概率收缩，冻结后在新的外部数据验证；若由代码采样最终动作，应明确这是“LLM + 统计校准器”的混合策略。

2. **歧义题的检索间接使用了隐藏概率。** `choices13k.py` 对完整分布计算 EV，`prepare.py:51` 生成 EV-gap，`sampling.py` 将其分箱，`retrieval.py:51` 将该分箱用于 matched 检索；`prompts.py:12` 则对歧义题隐藏 B 的概率。因此“检索只使用参与者作答前可见信息”的表述需要修正。这里不是 target human label 进入提示，而是检索使用了任务中隐藏的属性。

本次在 development 的 58 道歧义题上保持目标对象不变，仅将其 EV-gap bin 分别设为 small/medium/large，58 道的检索结果均发生变化。这证明该字段实际影响示例选择，尚未测量它对回答和 MAE 的因果影响。final 中有 76 道歧义题。

下一版对歧义题禁用不可观察的 EV、variance 及其派生检索特征；需要分箱的可见特征，其阈值只从训练/pool 确定。给新方法独立名称和配置，保留旧冻结实现用于复现。

3. **行号互斥不等于赌局从未出现。** final 的 6 道 no-feedback 题与旧 pilot 的 feedback 题有相同经济赌局结构。匹配时合并同收益结果、移除零概率项、排序结果、允许 A/B 交换，并保留 ambiguity 与 Corr；未使用人类标签匹配。

| Final item | Pilot item | Pilot feedback |
|---|---|---|
| 333 | 334 | True |
| 567 | 568 | True |
| 743 | 744 | True |
| 3266 | 3267 | True |
| 5728 | 5729 | True |

这没有推翻原来的行级互斥审计，也不是同一条件下标签的直接复用；但“400 道从未出现的赌局”比证据支持的范围更强。应表述为 400 条新 no-feedback 记录，并披露跨 feedback 条件的结构重合。后续外部数据和 split 应增加赌局/信息集层面的 canonical fingerprint，而非仅检查 row ID 或内部 Problem ID。

4. **改善并不完全依赖以上两类目标题。** 本次对冻结的 final 响应作了事后敏感性分析，没有重新调用模型，也没有改变最终方法：

|---|---:|---:|---|
| 非歧义题 | 324 | −0.03127 | [−0.05370, −0.00797] |

5. **概率拟合与个体异质性需区分。** Choices13k 的人类比例来自参与者重复选择后的聚合，而不是独立的单次 Bernoulli 参与者计数；官方说明每位参与者每题选择五次。将比例舍入成十条伪选择是展示编码，不能恢复真人个体的风险参数、时间一致性或行为相关性。不能把同一模型的十次随机响应直接称为十种持续存在的投资者。[官方数据说明](https://github.com/jcpeterson/choices13k)

**优先研究问题**

- RQ1：人类示例提供了多少有效行为信号，多少改善仅来自减少极端选择、位置偏差或通用概率收缩？
- RQ2：这种信号能否迁移到新来源的人类选择，尤其是持仓约束下的交易与社会信息反应？
- RQ3：在固定市场机制下，通过金融行为验证的策略，是否缩小模拟市场与人类市场的差距？

原先的“更高 herding 必然带来更多 switching”不应继续作为默认单向假设。多数跟随、交易参与、逆向交易和风格切换是不同结果变量；方向需要由具体信息结构和真人数据决定。

**E1：先解释已有提升，再增加复杂度**

修正后的 matched 规则只依赖可见信息。标签置乱对照应保留示例赌局及总体标签分布、打乱题目与人类选择的对应关系；50/50 示例对照检查中性示例是否同样能减弱极端选择。所有新对照冻结随机化、长度处理和位置平衡。B1 已有清楚的负结果，可保留在论文表格中；是否再跑由新问题决定。

可以先取旧 development 中预先确定的 200 题，5 个 LLM 方法 × 每题 10 次 = **10,000 个有效响应**。它们是方法开发数据，绝不改名为 untouched。基础模型调用尽量在同一批次交错运行，记录返回模型和后端信息，避免时间漂移与方法混淆。

判断规则：真实标签优于置乱/中性示例，才增强“学到了人类行为对应关系”的解释；相近则优先研究概率收缩或格式效应。不要把开发集中 matched K4 的最低点估计解释成它显著优于 random 或其他 K。

维持 item 为统计单位。十次采样只有 0.1 的率分辨率；独立同分布 Bernoulli 近似下最坏标准误为 0.158，仅是量级参考，因为本设计分两个展示方向且模型调用未必独立。可在按可见特征预选的少量旧 development 题上增加重复数，估计采样稳定性，不能只挑误差大的题补采后合并主结果。

**E2：CPC18 是有用候选，但要准确命名泛化范围**

CPC18 官方数据说明包含 CPC15 的前 150 个问题及新收集的问题；其 calibration 概览为 210 个问题，每题先进行五次无反馈选择，再进行有反馈选择。Choices13k 官方 README 说明其呈现设计沿用了 CPC15/CPC18。[CPC18 官方说明](https://cpc-18.com/data/)、[Choices13k 官方说明](https://github.com/jcpeterson/choices13k)

因此可把去重后的 no-feedback 部分用作**相近任务家族中的跨来源验证**；目前没有完成逐题跨库重叠审计，也不能称为与 Choices13k 无关的外部任务或无预训练污染测试。归档原始文件、commit/hash、许可及参与者来源，先以分布和可见信息指纹排重，再确定实际 N。不要预设 CPC18 能提供 1,000 道合格新题。

保持 Choices13k calibration pool 和新方法冻结，外部目标标签只在评估阶段使用。若要用 CPC18 自身标签调参，应另设 adaptation split，并将结论改称外部域适配。示意预算：200 个合格 item × 3 个 LLM 方法 × 10 次约 **6,000 次**；实际以去重后的 N 为准。

**E3：优先验证社会信息下的交易行为**

建议先做“私有信号与群体行为冲突时的交易/不交易决策”，它与已有单边 BUY 问题直接衔接；随后再加入持仓盈亏引起的卖出倾向。relative performance 与 Fundamental/Technical switching 暂列扩展，不同时覆盖五种偏差。

一个已核实存在的候选是 Drehmann、Oechssler、Roider 的金融羊群互联网实验：期刊页链接的 replication package 包含 `individual.sav`、`data.xls`、说明书和分析程序。作者结果显示，在该实验的信息结构下，灵活价格抑制羊群，提醒我们不能以“跟随率越高”代表“越像真人”。本次只核实了论文和文件清单，尚未确认变量是否足以重建决策前信息集，也未下载并验证原始微观数据。[原论文](https://www.aeaweb.org/articles?id=10.1257/000282805775014317)、[复制数据](https://doi.org/10.3886/E116068V1)

选库门槛：具有参与者/场次标识，能重建决策时可见的价格、信号和历史，明确动作集合与收益规则，能够复现至少一个原论文行为统计。若两天内不能取得满足条件的数据，切换候选，不先编造“真人目标率”。自行设计的 vignette 在没有对应真人回答时，只能用于软件和机制检查。

尽可能寻找同时含个人决策和市场结果的人类 CDA 数据，以场次拆分校准与测试，从同一实验制度连接微观与宏观。近期实验资产市场复制研究包含 166 个市场和 1,544 名参与者，可作为进一步筛查线索；本次未核实其可下载的订单级数据和许可。[作者工作论文](https://www2.uibk.ac.at/downloads/c4041030/wpaper/2024-12.pdf)

金融 benchmark 应按参与者/场次分组拆分，避免同一人的轨迹或同一市场同时出现在训练与测试。保留同一 agent 在多轮中的稳定属性，检验重复情境一致性，不能将每轮独立随机回答当作持续的个体异质性。

先沿用原实验的动作集合，只有数据确实支持时才扩展为 BUY/SELL/HOLD。若同一可见状态有充分多人回答，可比较动作分布误差；若状态基本唯一，以个人动作 Brier score 或预先固定平滑规则的 log loss 为主，并按参与者/场次聚类推断。不能把单个人的一次动作称为该状态的真实概率。社会跟随指标应控制私有信号和价格，同时报告 HOLD 与逆向交易。

建议比较 vanilla、通用风险校准迁移、金融域人类示例校准，并加入 logistic/随机效用等简单数据驱动基线。若只有金融域校准有效，应明确是校准方法迁移成功、Choices13k 所学行为本身未直接迁移。示意规模 150 个预定义状态 × 3 个方法 × 10 次 = **4,500 次**，实际设计取决于真人数据结构。

**E4–E5：在受控环境下重接市场**

先建立中性环境：单资产、明确基本价值过程、没有真实公司名称和新闻；固定初始现金/持仓、到达顺序、私人信号分布和外部冲击。可基于真人实验制度设置初始资源或私有估值异质性，但不得为得到成交而按 treatment 强制分配买卖方向。

先用规则和脚本代理做廉价参数筛查，再冻结共同的流动性制度。需要背景流动性时，应限制资金、库存与报价容量，并使用与 treatment 无关的策略；分别记录 agent–agent 和 agent–background 成交。额外现金或股息若进入系统，要由独立账户或显式现金流账本核算。

LLM 筛查示意为 30 agents × 30 sessions × vanilla/calibrated × 3 seeds，约 **5,400 个订单调用**，另加策略复盘及重试。3 seeds 只适合筛查。主实验的独立 run 数根据筛查方差、最小相关效应和功效计算冻结，不把“10 个 seeds”当成自动充分。交易日或 agent-day 不能代替独立 run 数。

门槛包括订单有效性、双边订单时段、非零成交期、agent–agent 成交占比及价格观测数量，具体数值随人类实验制度预先确定。若某策略导致不成交，这是需要保留的策略结果；不得筛掉失败 run 后只在幸存市场上比较真实性。流动性失败可以终止昂贵的价格影响扩展，同时保留其机制价值。

主实验尽量只改变“是否行为校准”，风格复盘机制、LLM temperature、订单映射、记忆长度等保持一致。若必须改变这些组件，应单独设置对照。固定仿真 seed 能配对初始状态与外部随机过程，不能宣称远程 LLM 输出也严格复现。

优先宏观目标为与人类实验制度匹配的价格偏离、换手/成交率、订单失衡和流动性；预先确定主要距离指标、标准化尺度与权重。应比较到独立人类目标的距离，而非简单奖励更大波动或更多成交。波动聚集、尾部指数需要更长且有足够有效价格变动的序列，23–30 个观测的路径不适合承担这些主结论。

只有在微观改善和宏观距离下降都得到验证时，才支持“校准带来市场拟合改善”的特定实验结论。若要进一步归因于某个行为通道，需要标签置乱、社会信号开关或固定执行规则等机制对照；不能仅凭微观和宏观指标相关声称中介机制成立。

**时间、预算与停止规则**

| 时间窗口 | 优先交付 |
|---|---|
| 第 1 周 | E0 归档；金融候选数据审计；E1 新协议与开发结果 |
| 第 2 周 | 冻结方法；有限规模 E2；E3 数据适配及人类统计复现 |
| 第 3–4 周 | E3 独立测试；按结果冻结市场策略；E4 筛查 |
| 第 5–6 周 | 通过门槛后做 E5；整理正结果、负结果与适用范围 |

前三类 LLM 小实验加市场筛查的示意调用量约 25,900 次，另加复盘、补采和重试；不包括市场主实验，也不代表已批准或已冻结的预算。不同提示词长度差异大，必须按实际 token 统计，当前没有可靠价格表，不换算货币费用。

若时间只有 1–2 周，优先做信息边界修订、简单基线、一个金融数据集的可复现适配和小规模验证。若有 8 周以上，再增加第二模型和长期动态；跨模型能扩展范围，但不能替代金融域验证。

暂缓 LoRA/SFT/RL、更多股票新闻、更多 persona 文案、复杂社交网络和大规模市场矩阵。若真标签不能优于无信息对照，先解决校准机制；若金融迁移无效，保留通用风险选择结论并研究领域校准；若市场仍单边，保留流动性失败结果，不强行扩展事件研究。

能够完成的最小论文主线是：冻结 persona 的负结果、人类示例对原始 LLM 的改善及严格边界、一项金融行为迁移验证、一个受控市场后果实验。若动态行为尚未验证，论文中应把“adaptive”保留为系统能力或未来目标，避免作为已证明的贡献。
