# 旧记录检查：未见编号复用，下一步拆开看策略变化

**本轮检查的旧模拟记录没有发现响应编号重复，540 条旧 AI 策略选择都仍能对应到唯一的原回答。** 但旧提问各不相同，没有同一提问的多次成功复测机会，不能用它证明接口不会复用，也不能替上一轮的独立复测提供保证。

## 这次查了什么

范围固定为九次旧 AI 运行的请求与响应，加上此前已核实的策略选择映射，共 20 份文件。实际读到 6,936 条请求、6,937 条响应；成功响应有 6,936 个不同编号，提问内容也有 6,936 种。

额外记录已分开：186 条是标记为格式修复的补问，1 条是失败后的重试响应。没有把它们一概叫作返回复用，也没有把它们算成更多投资者。另有 373 组回答文字重复，但编号不同；单靠文字相同不能判断是否缓存。

原来的 720 次策略复盘仍全部保留：540 次 AI 选择逐条核对，180 次程序规则单列排除。这里的 540 是选择次数，不是 540 位真人。订单类响应只检查了返回与提问的对应关系，不代表已经成交。

因此，这批旧统计继续保留；上一轮 16 次请求出现响应编号复用的限制也继续保留。两批记录不能互相替代，更不能推广到其他未经检查的实验。

## 独立审查修了什么

同一个独立子 agent 找到两处问题。一处会在同一请求有两条相反的有效回答时，挑出符合旧结论的一条。现在先确认有效回答唯一，再核对旧汇总中记录的选择；无法唯一确认时明确标为不确定。

另一处是报告曾把“没有相同提问的复测机会”误写成“没有重复编号”，现在分别说明。两处都加入了反例；另补了本地缓存回答可对应旧选择、却不算新生成的检查。

相关检查累计 **242 项通过**。修复后，汇总、逐条响应索引、策略映射和重复分组这四份数据输出，与初次结果逐字节相同。独立审查还直接读取固定来源复算，确认本批真实结论没有变化。旧代码修改前版本和初次结果均另行保留。

## 下一轮为什么换方向

独立子 agent 建议先拆开看“原来用什么策略，最后选了什么”，不要继续只看总切换率。基本面策略主要比较价格与系统参考价值，技术策略主要看价格走势。

为确定方向，双方已对这 540 次选择做了一次初步分组。第一轮每种设置都是 45 次基本面、45 次技术策略机会；第二轮的原策略构成已经不同：

| AI 设置 | 第一轮：技术改为基本面 / 技术机会 | 第二轮：原基本面 / 原技术机会 |
|---|---|---|
| 普通提示 | 44 / 45 | 89 / 1 |
| 低跟风提示 | 38 / 45 | 83 / 7 |
| 高跟风提示 | 23 / 45 | 68 / 22 |

这些数值只是选择下一轮方向的探索统计，尚未替代旧正式汇总。它们说明，总切换率会混入不同移动方向和第二轮构成的变化。第一轮起始策略数量相同，也不表示各组账户、收益和其他信息完全相同；不能直接把差异归因于提示。

下一轮将把两个复盘日期分开，再逐次运行展示所有起始策略与目标策略的组合，并保留全部 540 次选择的对应证据。不把“换得多”叫作“更跟风”，也不把“换得少”叫作“更像真人”。

## 对照 RP，进度到哪

关于 AI 怎样改变策略，现在可以更可靠地核对已有选择，并找出总指标掩盖的信息。**还没有证明跟风机制、真人相似度或市场真实性。** 本轮没有新增模型请求、没有打开保留的真人测试数据，也没有运行新市场。

累计模型请求仍为 **21/21 次**；下一轮上述分组分析可以离线完成。SCIT 批量优化继续暂停，旧实验、49 个已批准候选文件和旧交付 ZIP 均保留。
