# 三个完整训练日的逐笔价格诊断

2026-10-15 整理。11月1—3日的完整执行与精确汇总已于10月13日完成，覆盖
4,371,215 条独立公开打印、五种信息延迟，共21,856,075条比较记录。
[独立复核](crypto_execution_full_train_review_20261015.md)已通过全部保留残差、分位数、
固定分层、区块和等权日汇总；原始盘口另外按预先固定的128笔/日复算，
不能将该抽查描述成每条真实盘口状态的全量独立重放。

结论限于已知实际主动方向和数量时的成交价格代理：可见深度扫单比只看最优一档
略好，改善主要见于跨档样本；信息变旧后，两者误差都增大。平均误差的改善
不能保证尾部改善。它没有证明自主市场逼真，也没有恢复真实整张主动订单。

## 比较规则

每条打印使用其时间之前严格可用的盘口前缀；发布时间采用固定代理，额外信息延迟为
0、10、50、100、250ms。每次价格计算独立扫可见深度，不改写历史盘口，不利用实际
成交价选择预测价格。真实成交价只用于事后误差。误差单位bps，1bps=0.01%。

为比较延迟，只保留五个延迟均合格的同一组打印，共4,371,101条；其中五个延迟均跨过
最优档的同一子集为56,557条。跨档条件使用给定打印量与对应前缀最优档量，不能解释为
实际parent order跨档。日间汇总给三个完整UTC日相同权重，不按交易更活跃的日期加权。
P99由所有保留的float64误差按经验inverted-CDF顺序统计量计算，没有抽样或分位数草图。
