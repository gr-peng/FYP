# 加密市场真实性：持续研究协议

用户要求先做加密市场，持续寻找真实模拟方法、自行寻找缺失数据，并由独立agent评测完成度和提出idea。此目标保持开放；取得数据、通过工程测试或跑完一组实验，均不代表整体完成。上轮双事件实验的负结果继续保留。

独立审查已指出：当前现金/库存撮合内部一致，但真实LOB重建、外部成交验证、内生价格真实性和真人行为增益都未建立。新的工作按这四层分别验收。独立评测agent不得把自己的建议当成验证结果，最终须检查原始数据、实现及留出结果。

数据搜索已实际取得2024年大选期间Bybit BTCUSDT 500档快照与增量样本，以及同一交易所逐笔成交。该品种是USDT永续，不是此前Binance现货。首先研究其可见盘口和订单流；尚未补齐历史保证金、资金费、标记价格及强平制度时，不声称已完成该合约的交易账户模拟。

配置为`config/crypto_microstructure_20261011.json`。完整时间块提前固定：11月1—3日训练，11月4日开发，11月5—7日事件最终检验。此前11月4—7日各约一分钟文件开头只用于来源和格式探测，不用于选模型。最终检验允许归档、CRC、schema、时间覆盖与数据质量检查；不得在模型和评价方法冻结之前生成价格/深度分布报告或模型分数。既有真人金融最终测试16场仍不打开。

原始URL、响应长度、ETag、SHA256和下载时间保留。ETag不当作内容SHA256；本地hash只是归档完整性，不冒充发布者签名。ZIP/GZIP解压CRC须通过。无法恢复的时间/序列异常要保留并切段，不能前向填补为无缺口。Bybit `seq`跨多个盘口深度，不能要求每条加一；`u`的单步变化只能作为单条订阅档案的连续性诊断，不能替代独立快照或校验和证据。

价格和数量采用精确整数存储，尺度100与1000来自样本表示精度，不称为已证实的2024年交易最小步长。snapshot替换整本，delta数量为绝对数量，零删除。聚合L2无法唯一分解新增/撤单/改单，更新间发生的事件也可能相抵。拟合对象须称为可见深度变化，不能伪称已识别逐单到达强度。

第一层验收：重建期间不负量、不交叉，按场所语义处理重快照、乱序及失效；有独立快照/校验或明确记录缺少该证据。第二层：主动单逐档消耗可见数量，超深度不能无依据全成；被动队列只能在有数据支撑下验证，否则报告假设范围。历史影子单不能修改后续真实绝对深度后，又宣称有真实反事实冲击。

第三层先比较固定LP、训练期拟合的简单可见订单流、状态条件化过程。生成时只读取起始状态，不能输入真实后续价格或订单流来维持曲线。指标同时覆盖价差/深度/失衡、成交与更新率/聚集、秒与分钟收益/零收益/绝对收益自相关、订单流与价格联合关系。阈值须依据训练期跨日自然变化制定并在最终检验前冻结；不能事后挑选最像的指标或种子。

第四层才检验LLM的额外价值：优先让其在较慢频率提供仓位目标和紧迫度，由同一确定性执行器负责数值约束。规则、统计与LLM共享制度；微观和宏观增益分别评分。钱包地址不等于真人心理标签，知名历史事件仍可能被模型记忆。
