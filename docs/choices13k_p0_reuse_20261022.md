# 旧风险选择记录：20题中19题出现返回复用迹象

**预先选定的20道题中，有19题出现了相同回答编号、生成时间和正文的重复返回。** 这意味着，旧实验里“每题收到10份答案”，不能自动解释为模型独立作了10次选择。

| 本轮核对内容 | 实际结果 |
|---|---|
| 预先选定题数 | 20道 |
| 原来的回答机会 | 每题10个，共200个 |
| 唯一对应到有效原始回答 | 200个 |
| 不同的编号、时间、正文组合 | 144种 |
| 上述组合再次出现的次数 | 56次 |
| 出现重复组合的题 | 19道 |
| 实际独立生成次数 | 无法确认 |

144只是不同返回组合的数量，不能当成144次独立生成。详细记录中有42组重复组合，涉及98份接收记录；这里的56是每组首次出现之后再次出现的次数。没有把这些记录删掉，或据此重算一个“去重后的选择概率”。

每题原来有5次A先显示、5次B先显示。本轮把它们按实际完整提问分成40组，每组5个机会；其中30组发现相同编号、时间和正文重复，所有重复都出现在相同完整提问内。二选一答案本来就容易同为A或B，本次依据包括编号和生成时间，并非只因为答案文字相同。

200个主请求均有记录到的发送尝试和成功返回，没有本地缓存回放、格式修复或无法确认的机会。这些是九月保存的旧记录，不是本轮新调用。没有本地回放标记，只能说明当时本地程序走了发送路径，不能排除接口其他位置复用了回答。未发现重复的那一道题，也不能据此确认独立生成。

题目在看AI答案前已固定：从原先冻结的200道校准题中，按题号升序选前20道，仅读取题号列。日志中的其他提示正文不解析，汇总文件只核对指纹，真人答案列和封存测试不读取。读取器先核对身份和正文位置，再只解析选定的原始提示（P0）记录。

本地24项检查通过。在独立审查后修复了两处工具关联漏洞：重试编号格式异常、修复回答缺少对应发送记录时，现在均保留未知。反例都使用虚构文件，旧数据的初步实际核对没有出现这些异常。原工具版本、初次测试及旧正式结果均保留。

对照RP，本轮检查的是“AI选择频率”的依据，尚未证明AI更像真人或市场更真实。结论仅覆盖这20题、P0校准记录，不能直接推广到其余180题、其他提示或封存测试。本轮未读取真人答案、未重新挑提示，也没有覆盖原误差指标。

独立子agent已从固定来源完成独立复算，验收了实际结果和报告。它确定下一轮一次核对全部200道校准题的P0旧记录，共2000个机会，仍不新增请求、不读真人答案。那是看过本轮20题后作的覆盖扩展，会明确区分已检查20题和新增180题。本轮新增模型请求**0次**，累计仍为**59/100次**，剩41次。
