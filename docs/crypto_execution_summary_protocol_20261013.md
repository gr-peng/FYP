# 逐笔成交条件诊断：固定汇总规则

2026-10-13，首次真实工程冒烟前记录。执行核心已独立审阅，配置中的窗口
固定为 2024-11-01 00:00—01:00 UTC。后续完整训练诊断覆盖 11 月 1—3 日；
开发与最终事件期仍关闭。汇总只读取成功、不可覆盖且 hash 匹配的执行产物，
不另读原始行情，也不修改成交或盘口对齐规则。

预测量沿用可见扫单、最优对手价、中间价。主比较为同一完整覆盖且盘口年龄
小于一秒样本上的 `sweep − opposite-L1` MAE，跨 L1 成交另列。所有五个延迟
`0/10/50/100/250 ms` 全部展示，并展示五延迟共同合格、共同跨 L1 的交集。
未知整张主动单、公开逐笔与盘口之间的时钟偏差以及不可见流动性限制继续保留。

分层沿用既定 side、age 和 quantity/L1 bins；不按误差删除日期、成交或分组。
先给候选逐笔数及 no-state/invalid/outside-day/stale/partial 等排除分母，
空层保留零样本数与缺失误差，不填零。各层三种预测量共用配对样本。
超出可见数量的余量不外推为成交；可见数量覆盖不称为实际成交率。

分位数固定 median、P90、P99，定义为经验 CDF 的逆，即 NumPy
`quantile(method="inverted_cdf")`。按日、延迟及固定分层使用全部被保留的
float64 bps 残差精确计算，不抽样、不用 sketch；“精确”指经验分位数不近似，
不表示 float64 是无限精度有理数。原始价格、数量及成本整数仍保留，可复核
每条残差的有理数公式。分位数不会从一小时外推为整日或总体尾部风险。

一小时输出标记为窗口诊断。只有覆盖预定完整自然日的结果，才提供逐日
MAE 差值及等权日均比较；不把更多成交笔数当独立样本，不做秒/逐笔 IID
显著性或置信区间。逐笔加权 MAE 与等权日均值分别标识，不能挑更好聚合。

执行 manifest、prepared receipt、协议/源码/输入 hash 与实际 Parquet hash
均需核对；不完整或失败运行、篡改、缺延迟、重复逐笔或越界行必须拒绝。
汇总程序另存独立源码身份、输入身份与不可覆盖的结果。配置原已明确
流式执行摘要不计算分位数；独立后处理负责补齐，不追改旧执行产物。

本阶段只检查实际逐笔方向与数量给定时的价格代理。工程通过、零误差率高
或小成交准确，都不能单独证明整单成交、被动队列、代理冲击或市场生成真实。
