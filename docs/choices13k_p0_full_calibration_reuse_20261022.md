# 旧风险选择记录：完整200题核对

**原来200道校准题中，有196道出现相同回答编号、生成时间和正文的重复返回。** 因此，旧实验里“每题收到10份答案”，不能自动解释为模型独立作了10次选择。这个问题覆盖了大部分题目，需要收紧对旧结果的解释。

仍可描述实际收到的选择频率。现有证据不足以把它解释成独立生成的模型选择分布；发现复用，也不等于旧平均误差数值必然算错。

| 本轮核对内容 | 实际结果 |
|---|---|
| 题数 | 200道，其中20道之前已检查、180道本轮新增检查 |
| 原来的回答机会 | 每题10个，共2000个 |
| 能对应到有效原始回答 | 2000个 |
| 出现相同编号、时间、正文重复的题 | 196道 |
| 不同编号、时间、正文组合 | 1368种，不能当成独立生成次数 |
| 同一组合首次出现后，再次出现的次数 | 632次 |
| 本轮新增模型请求 | 0次，累计仍为59/100次 |

重复返回共415组，涉及1047份接收记录。这里的632次只表示每组首次出现之后又出现了几次，不能当成缓存比例，也不能据此倒算实际生成次数。二选一答案本来就容易相同，本轮还核对了回答编号和生成时间，没有只凭答案同为A或B判断。

每题原来有5次A先显示、5次B先显示。按实际完整提问计算，共400组，每组5个机会；335组出现重复返回，所有重复都发生在相同完整提问内。没有发现重复的4道题，也不能据此确认独立生成。

记录中有2001次发送尝试：其中一次收到502错误后重试成功。这仍是2000个回答机会，没有多算一次。没有发现本地缓存回放、格式修复或无法对应的主回答；但本地程序记录了发送，并不能排除接口其他位置复用了回答。目前不能确定复用发生在哪一层。

这是看过前20题结果之后的完整覆盖扩展，使用同一批旧记录，不能算一次独立重复实验。检查范围为原始提示（P0）的校准记录，只从校准表读取题号列，不读取真人答案、其他提示正文或封存测试。全部200题和2000个机会在读取新增180题回答前固定。原20题的200行结果已经逐行与旧结果比对，完全一致；旧结果与旧报告保留。

工具保留原有24项检查，并新增7项虚构数据检查，31项全部通过；独立审阅也复跑了31项检查。独立子agent随后从固定范围的原始记录重新核算，验收了实际2000个机会、重复计数、一次重试、原20题逐行一致，以及报告中的数字和解释。

对照RP，这轮完成的是“实验依据能不能信”的核对。它尚未证明AI更像真人，也未证明市场更真实。不能直接把2000份接收记录当成2000次独立选择，再据此宣称提示方法更有效。本轮没有读取真人答案、重挑提示或重算旧误差。

独立审阅确定下一轮回到RP的核心问题：这些实际收到的选择，离真人有多远。先固定全200题和计算方法，再只开放同一校准表的题号、真人选择比例两列；按A/B显示顺序还原原选项，保留每题全部10份返回，比较观测比例与真人比例，也对照“始终各选一半”的简单基线，并单列两种显示顺序的差异。它只是一份校准题上的探索性对照，不重新挑提示，不宣称独立采样、真人行为机制或封存测试通过。这个计划尚未执行，本轮仍未读取真人答案。
