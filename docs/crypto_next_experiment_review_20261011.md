# 下一项加密市场实验：独立设计评测备忘录

2026-10-11，独立评测agent；依据`f7f0d2e`及已审查的数据、账户代码。本备忘录是建议，不是新实验已冻结、已运行或已经通过的证明。未读取11月5—7日市场统计。

**建议下一项实验检验“给定已知盘口，状态条件化的有效订单流，能否在留出时段生成更可信的短期盘口与成交”。** 先做5分钟局部市场，不以重现大选整月涨幅为这一步的通过条件；原始真实市场模拟目标继续开放。先不加入LLM，避免把背景市场的错误与投资者政策混在一起。

当前已经有真实档案、精确L2重建、可见盘口扫单、带时点的特征与独立永续会计模块。工程检查不能证明真实队列、反事实冲击、清算或真人偏好。完整档案审计及留出结果仍须以最终产物核验。

**数据能识别什么。** 约100ms聚合L2提供发布时的可见价位总量；逐笔成交提供已实现的成交价、数量、方向和时间。它们不能唯一恢复每张订单、先后排队、撤单位置、区间内补单与吃单顺序，也不能识别加入新代理后其他参与者会怎样反应。对共同可见的绝对价位，可考察“深度变化＋可对齐成交消耗”的净剩余变化；它仍不是新增/撤单的各自总量。500档边缘移入移出要标成截断，不能直接计作挂撤单。未对齐成交或无法分解的100ms区间必须保留不确定性，不能偷偷选出能重建价格的一条微观路径。

[Queue-reactive研究](https://arxiv.org/abs/1312.0563)提供了让订单流依赖当前盘口的建模思路；本档案不能支持照搬其逐事件可识别性。这里应明确称为“有效聚合订单流模型”。[Bybit协议](https://bybit-exchange.github.io/docs/v5/websocket/public/orderbook)支持快照重置与绝对量更新，并不保证聚合更新揭示区间内全部订单。

| 对照或候选 | 具体用途 | 不能据此声称什么 |
|---|---|---|
| R：真实历史回放 | 检查重建、时钟、单位；价格吻合作为程序校验 | 代理生成了真实行情 |
| P：训练期价格/成交量块重采样 | 强制保留一个便宜的统计价格基线，比较价格分布与预测分数 | 具有内生订单簿或成交机制 |
| M0：不依赖当前状态的有效订单流 | 在同一撮合器、初始盘口和数量约束下生成买卖、补充与移除 | 学会了市场对状态变化的反应 |
| M1：依赖当前价差、深度失衡、过去成交压力的有效订单流 | 唯一主要候选；检验状态依赖是否改善留出表现 | 已识别真人策略或真实逐单事件 |

M0/M1均应由合成订单与成交改变自己的盘口。开始后不得读取该测试窗口的真实未来价格、深度或交易来重新定中心、补回库存、修正负量；否则降格为条件回放。若实现只抽取“下一秒收益”再整体平移盘口，须归入P类。合成背景的资源、深层边界补充、撤量上限与区间内事件顺序应在开发期固定，记录裁剪、拒绝、空簿和边界补充次数。成交消耗不能既在撮合时扣一次，又在净深度变化中重复扣一次。对不可识别的区间内顺序至少做两个预定、可行的顺序假设；若结论依赖其中一个，不判机制稳健。

**一个可执行的最小安排。** 11月1—3日只拟合参数、标准化与状态分箱；11月4日只开发。先固定每个UTC小时第10分钟开始的5分钟窗口、20个模拟种子及全部候选，起始状态只取该时点已可用的历史盘口。覆盖不合格窗口按预定规则标记不可评分，不事后换成更好窗口；每种方法共用相同窗口。每个窗口只初始化一次，生成5分钟；评分同时看1秒、60秒及整段结果。冻结代码、参数、指标、阈值和数据hash，并通过程序的冻结校验后，才开放最终检验并评估11月5—7日；不能拿这些日子的分布先定阈值。种子只是蒙特卡洛重复，不是额外的真实交易日。

时间以各特征的`available_at_ms`为准，禁止按桶起点对齐。L2发布时间不是客户实际接收时间；成交CSV主要给出成交时点，不能把“桶结束”冒充已测量的消息到达时点。先声明理想可见时钟，并统一做1秒与5秒额外信息延迟敏感性；这不是延迟已经验证。任何预测/生成输入不得使用目标区间的成交或收益来定义当前状态。日边界、gap/reset、深度不足窗口单列，既不补造零收益，也不从评价分母悄悄消失。

**主要评分与通过条件。** 冻结一个联合主分数：对未来60秒收益、成交量与成交笔数、平均价差、双侧可见5bps深度、成交方向失衡组成的向量，使用训练期固定尺度的多变量energy score；另报各变量的分布误差与90%预测区间覆盖，防止一个变量掩盖另一个。M1需在留出窗口上优于M0的配对主分数；其价格子分数还需与P比较，不能仅胜过明显失真的固定LP。另固定检查零收益/空簿率、绝对收益自相关、成交方向持续性，以及当前盘口失衡/成交压力与后续价格变化的联合关系。仅匹配收益直方图不算通过。区间应按完整时间块和交易日结构处理；只有三个最终事件日时，逐日结果比伪精确的总体显著性更重要。

通过须同时满足：工程不变量全部成立；没有未来输入；留出主分数达到冻结的实质改善标准；各关键真实性指标落入预先有依据的容差；结果不由单日、单种子或单个未识别顺序假设支撑。任一关键项明显偏离则失败；容差依据不足、覆盖不足或误差区间太宽则是“证据不足”，不能算通过。

**只有三个训练日，不能可靠估计所谓自然波动的95%通过阈值。** 可展示训练日间差异作为诊断，但不得将训练块大量bootstrap后得到的窄区间当成新交易日的分布。若研究用途能给出可解释的绝对误差容差，应在看最终检验前写明理由；否则本轮只能做开发诊断与模型排序，不能宣布等价真实市场。需要扩数据时，先声明连续、按日历选取的额外较早日期及新训练/验证划分，再下载和查看；保留原事件检验封存。不得挑波动最接近大选的训练日、用事件日定容差，或因未通过而放宽阈值。

**执行外部效度单独评分。** 可见盘口扫单是零延迟、有限可见深度下的成本函数校验。把历史成交与严格更早、当时可用的盘口配对，按档案年龄与方向比较实际成交价是否兼容，只能检验数据和执行代理的一致性：同一主动单可能拆成多笔，补单和延迟也不可见，不能自动恢复整单VWAP。缺少独立订单提交、成交回报和延迟数据时，被动成交率、真实实现滑点与冲击因果效应标记“未识别”。对生成市场加入固定小额主动单、检验数量—即时成本单调性和后续响应，只是机械压力测试；与自然订单流相关的价格响应相似，也不能代替真实干预验证。

若M1通过上述留出检验，可以说“这套有效订单流在规定场所、时段及短期指标上获得外部支持”。即使P或M1的bootstrap分布很像历史，也不能直接说已真实模拟加密市场。之后仍需独立执行数据、更广市场状态与永续制度验证，最后才在同一背景下比较规则、统计与LLM的额外价值。
