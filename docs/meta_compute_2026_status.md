## 已观察到的结果与限制

- 真实 NVDA 从实验前一交易日收盘到 7 月 17 日收盘的价格收益为 -1.16%，窗口最大回撤 9.38%。以 QQQ 为基准、在预事件窗口估计 beta 后，E1 和 E2 的事件日收益分别为 -1.25% 和 -0.66%，各自的 ±1 交易日累计异常收益（CAR）分别约为 +2.23% 和 +4.90%。这些共时数据不能将 NVDA 走势归因于 Meta 新闻。
- 历史回放的价格被真实行情固定，四组市场收益均为 -1.16%；可以比较的是订单、持仓、个人收益与风格变化。AIGC 中转站批次 3 个 seed 的平均 agent 收益：规则 -0.59%、Vanilla -2.27%、低羊群 -1.98%、高羊群 -2.09%。低/高羊群平均 agent 收益的探索性 Mann–Whitney 检验 p=0.70，没有可辨别差异。风格切换率依次为规则 75.0%、Vanilla 24.4%、低羊群 21.7%、高羊群 13.3%。
- 内生 LLM 市场在所有冲击下的最终价格都约为 205.19，表中约 `1e-8` 的收益是输出精度造成的数值残差，不是经济意义上的价格反应。Vanilla 在 0%、-2%、-5% 下平均成交 1.3、0.7、4.3 笔/运行；低羊群为 0、1.3、5.7；高羊群为 9.0、8.7、17.7。对应规则基线为 324.7、227.7、198.3 笔，并形成非零价格路径。LLM 组买卖单严重不平衡，价格和收益检验在近乎常数路径上没有解释价值；不能据此确认或否定新闻冲击及羊群放大效应。
- 完成运行的文件哈希、事件可见时间、未来信息过滤、订单/成交、现金和持仓守恒检查均通过：AIGC 中转站真实 API 48/48，SiliconFlow 早期批次 24/24，mock 48/48。历史回放的模拟 CAR 与真实 CAR 差值按定义为零。统计以 seed 级运行而非 agent-day 为样本；3 个 seed 的功效有限，也尚无人类行为数据校准。
