## 已观察到的结果与限制

- 真实 NVDA 从实验前一交易日收盘到 7 月 17 日收盘的价格收益为 -1.16%，窗口最大回撤 9.38%。以 QQQ 为基准、在预事件窗口估计 beta 后，E1 和 E2 的事件日收益分别为 -1.25% 和 -0.66%，各自的 ±1 交易日累计异常收益（CAR）分别约为 +2.23% 和 +4.90%。这些共时数据不能将 NVDA 走势归因于 Meta 新闻。
- 历史回放的价格被真实行情固定，四组市场收益均为 -1.16%；可以比较的是订单、持仓、个人收益与风格变化。3 个 seed 的平均 agent 收益：规则 -0.59%、Vanilla -2.46%、低羊群 -1.79%、高羊群 -2.43%。低/高羊群平均 agent 收益的探索性 Mann–Whitney 检验 p=0.20，不能据此宣称稳定差异。
- 已完成的三个 LLM 内生 0% 冲击运行分别只有 1、0、0 笔成交，价格几乎不动。订单诊断显示：Vanilla 两个运行各只有 2/690 个买单，低羊群运行有 13/690 个买单；三次运行合计只有一个交易日同时出现买卖单，该日成交 1 笔。相同冲击下，规则基线的三个 seed 分别在 22、22、23 个交易日同时出现买卖单，并各成交 297、344、333 笔。可见当前 LLM 配置首先缺少双边订单流，而非订单簿无法撮合；这不排除提示词、初始持仓和价值锚共同影响下单方向。高/低羊群内生效果以及冲击情景的完整比较尚不可得。不能把零成交解读为新闻没有影响，也不能据此声称已观察到或排除了市场放大效应。
- 完成运行的文件哈希、事件可见时间、未来信息过滤、订单/成交、现金和持仓守恒检查均通过：真实 API 24/24，mock 48/48。历史回放的模拟 CAR 与真实 CAR 差值按定义为零。统计以 seed 级运行而非 agent-day 为样本；3 个 seed 的功效有限，也尚无人类行为数据校准。

## API 状态与续跑

已记录 10,975 次 Chat Completions 请求结果，其中 10,048 次 HTTP 200、912 次 HTTP 429、3 次 HTTP 402；另有 12 次传输失败。本地缓存命中 9,339 次。按请求时段的公开价格和可见 token 用量估算费用约 ¥44.59，**不是账户账单**。9 月 14 日四个并行 LLM 运行遇到大量 429，随后因 402 中断；9 月 15 日一次最小检查仍为 402。402 的具体账户原因需由 key 持有人在服务商账户核查，当前不能继续付费推理。

代码已增加跨运行共享的每秒 4 次派发节流和 429 全局冷却；已完成运行可从缓存无付费重建，未完成运行将从已有响应缓存续跑。账户恢复后，在仓库根目录按[实验协议](meta_compute_2026_protocol.md)依次完成剩余 0%、-2%、-5% 内生情景，再重新生成报告、API 用量与审计。不要在中途更改模型、提示词或市场规则后把新旧运行直接合并比较；若为改善流动性而改设计，应另开明确标记的实验批次。

2026-09-15 已验证 HKUST(GZ) AIGC 中转站的 `/api/v2/models` 和 Chat Completions 接口，服务端模型 ID 为 `DeepSeek-V4-Flash`。新批次使用 `aigc_relay` 独立输出和缓存，从完整 48 次矩阵重新运行；SiliconFlow 的 24 次部分批次保留作独立的早期结果，不用于填补新批次单元格。
