# 这批旧 AI 选择，几乎只朝一个方向切换

**540 次旧 AI 选择中，共有 107 次切换：106 次从技术策略转向基本面，只有 1 次反向。** 因而，“切换了多少次”掩盖了重要信息：这批选择主要往基本面移动，不能把所有切换直接叫作跟风。

基本面策略主要看价格与系统参考价值的差距，技术策略主要看价格走势。以下只描述这批旧模拟记录，没有新增模型或真人实验。

## 按日期拆开后，看到什么

| AI 设置 | 第一轮：技术转基本面 | 第二轮：技术转基本面 |
|---|---|---|
| 普通提示 | 44 / 45 | 0 / 1 |
| 低跟风提示 | 38 / 45 | 1 / 7 |
| 高跟风提示 | 23 / 45 | 0 / 22 |

分母是当期原来使用技术策略的选择机会，每种设置合计三次运行。第二轮的原策略构成已经不同，不能把两轮合并后当作同一批条件下的机会。

我们还按同一运行、同一代理逐个对应了两期记录。**270 对全部显示：第二期原策略等于第一期目标策略。** 所以，第二轮人群构成确实延续了此前选择，不能当作新的独立起点。这个核对只确认旧记录中的策略状态衔接，没有证明整个市场或价格反馈真实。

第一轮各组虽然都是 45 次基本面、45 次技术机会，但账户、收益和其他信息是否相同并未成立。因此，这些差异也不能直接归因于提示设置。

## 这轮具体做了什么

新增了分日期、分运行的策略迁移工具，保留全部 540 次 AI 机会和另列的 180 次程序规则。每次选择都对应已有的原回答绑定，两个日期和九次运行分别展示。

工具把三种情况分开：确实没有某种原策略、记录缺失、原策略已知但回答未知。后两种不会补成“保持”，也不会把已匹配子集当作完整分母。普通提示的两次运行在第二轮已经没有技术策略机会，对应比例明确为空，不能写成零切换率。

相关检查累计 **262 项通过**。同一个独立子 agent 另行运行了 20 项新增检查，并直接从四份限定来源复算全部迁移格、540 次绑定及 270 对衔接；验收通过，无必须修复项。已通过的分析没有再重跑，验收后的输出按原字节复制到正式结果目录。

## 对照 RP，下一步解决什么

关于 AI 如何改变策略，现在已经从总切换率推进到具体移动方向，以及选择如何延续到下一期。**还没有证明这种行为像真人，也没有解释它为什么主要转向基本面。**

独立子 agent 建议下一轮先离线设计最小对照，区分三种可能解释：系统给出的价值或相对收益信号、保持原策略的倾向、群体多数信息。需要先列明提示来源及相互关联的字段，保证修改情境后账户、经历和收益仍然一致，避免为了看到跟风而改提示。

后续实际运行仍需解决响应复用与新生成如何核实的问题，并明确新增调用额度。本轮没有新增请求，累计仍为 **21/21 次**；没有打开保留的真人测试数据，没有运行新市场。SCIT 批量优化继续暂停，旧实验和已批准候选文件保留。
