# 100ms有效流提取：真实读取前的固定实施协议

2026-10-13。本阶段只提取训练标签，不拟合、生成或选择市场模型。纯分解与
经验模板池已经通过[独立核心审阅](crypto_effective_flow_independent_review_20261013.md)；
真实reader尚须独立通过后才能运行。开发期与事件检验保持关闭。
机器协议为 `config/crypto_effective_flow_extraction_20261013.json`，其所有字段
与程序固定常量一致才可读取档案；运行要求配置和全部来源文件与本地提交一致。

**固定范围。** 完整训练只读原11月1—3日，按UTC对齐100ms网格逐日流式
推进。首项冒烟固定11月1日00:10—00:15，正是自主原型计划的第一个窗口；
不能按行情重选。两种模式均从该日00:00顺序消耗原始前缀，冒烟仅输出规定
的3000个候选区间。`prepare-only`仅核对字节、来源和完整性，不解析市场行。

**真实时钟。** 复用已审阅执行cursor的未消费消息屏障和
`max(prefix_ts+1ms, cts+1ms, 原序列可用屏障)`；仅当可用上界严格早于观察
时点才应用消息。挂在pending中的消息不能修改簿，也不能绕过读后续消息。
本reader将每个有效原始snapshot（包括内容完全相同的duplicate）明确计为
reset边界；它不是一次有效巨额添加。原始`cts`与snapshot起点保持毫秒整数，
没有伪造客户接收时间。原始u/seq校验沿用保守重建规则，不代表已证明交易所
没有隐藏缺口、L3或真实队列可识别。

**因果输入与共同队列。** 在A处先取得O(A)、O(A−1s)、O(A−5s)，以及每个
signal时点之前完整一秒的打印，再消费[A,A+100ms)的标签。三种输入共用同一
候选队列；任一输入没有过去完整上下文、无效或过旧，都保留排除原因。
各延迟信号在自己的过去观察时点判断1秒状态年龄，不能把5秒延迟误作所有
状态都过旧；信号与标签起点必须同segment、同累计无效消息计数。首日最早
6秒不具有最大延迟所需的完整过去，不能以零成交补全。CSV打印仍采用理想
“成交时点可见”假设，未识别真实消息发布时间或传输延迟。

**分解与边缘。** 只在两端共同已知绝对价格域使用`q1−q0+C`。输出残量的
正/负部分只称有效净添加/移除；新增再撤销、未显示成交、端点打印错位都
无法由此恢复。共同域外端点数量与打印单列，不补零或外推。净价格事件的
存储顺序固定为买侧从高到低、再卖侧从低到高；这只是规范编码顺序，真实
区间顺序仍须S1/S2敏感性。打印保存原始行号/ID/方向/价格/数量与半开区间，
生成模板只取得方向/数量，不取得打印价格或终点簿。

**存储细化。** 为避免每100ms重复保存未变的500档，提取产物采用稀疏证据：
保存两端与三种signal的原始前缀index、可用/CTS/TS时钟、segment与错误计数、
L1/最外档/档数；所有非零残量或成交消耗价位保存精确q0/q1/C；打印与
截断诊断完整保留。未变价位可由完整raw SHA与前缀index重新重建，不能将
它们的省略解释为数量为零。拟合消费者不得只有一份无来源的稀疏模板。
真正初始化自主簿时仍须按同一批准前缀复制完整起始500档，不能用这里只
保存的L1和边缘补造中间价位。

**失败与身份。** 每次运行使用新目录，先核对当前来源配置、提交源码、
原始下载metadata、完整CRC/结构审计及实际raw字节hash，再保存prepared
receipt并解析。结束后重验来源/audit/metadata/raw字节与全部冻结代码。
未完成或失败的master绝不标记`outputs_published=true`；不能消费暂存的
逐日文件。每个gzip输出hash覆盖全部记录及完整模板内容，行数必须等于
预定网格候选数。随后拟合还需核验complete master、实际gzip字节及来源，
只允许`eligible=true`的共同队列；纯池的row-identity digest不能代替内容hash。

**本阶段的限度。** 通过提取检查只说明有效标签与已声明时钟、可见域一致，
不是自主生成或实际订单恢复。真实模板产物、完整M0/M1生成、P/R、五分钟
七维评分、延迟与两种顺序结果仍必须分别完成并独立复核。尚不开放事件期，
也不依据训练/冒烟改善宣告市场真实性。
