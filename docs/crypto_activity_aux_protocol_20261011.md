# 辅助自然周成交活动诊断：冻结规格与两阶段访问

日期：2026-10-11。当前是实施协议，尚无本实验开发周评分。此版本承接
[候选模型设计](crypto_activity_next_model_20261011.md)，不修改 November v1 的
代码、配置、结果或其负面结论。

## 研究边界与固定比较

参数只用 2024-10-14—20 拟合，评价日固定为 10-21—27，所有自然日均保留。
设计参考过 11 月诊断，故这是回顾性方法开发中的顺序参数检验，不能称为
从未受后来资料影响的前瞻研究。原 11 月 5—7 日和最终人类金融样本继续封存。

共同样本上的五个模型为 NB2 的 N0（活动/时钟基线）、N1（加盘口），以及
logistic + 零截断 NB2 的 H0、H1、Hnoise。Hnoise 在基线基础上加四个固定
SHA256/Box–Muller 正态特征，种子 20261011，由已知信号时间与维度编号决定。
它不匹配盘口的自相关或分布，也不是显著性检验的经验零分布。

全部模型在额外 0、1,000、5,000 ms 延迟下拟合和评价，共 15 个对象。
不增加 weekday、长历史、交互或正则搜索。共同样本、时间边界和重复目标
去重沿用 v1 定义，但使用明确的辅助日期门控，不覆盖或 monkeypatch v1 日期。
首个完整目标秒、服务端发布代理时间和成交桶最低可用时间的局限均保留。

训练标准化使用全部共同样本，不仅使用正计数子集。L2 系数固定 0.01；
截距与 alpha 不惩罚，alpha 范围 `[1e-4,1000]`。优化条件与 v1 相同。
hurdle 的目标是全样本平均负 log probability，加两部分斜率平方和的一半
乘 L2。正计数部分必须包含截断归一项，不能删零后直接拟合普通 NB。
完整均值是 `p*mu/(1-f_NB(0))`。失败对象不能静默替换或删除。

## 预定评分

主指标是完整计数分布的平均 log probability，并报告同全样本分母下的
二元与正计数贡献。列出全周加权值、每日值、日均差值、最差日、正值日数
及固定 UTC 三小时块。固定比较为 H0−N0、N1−N0、H1−H0、Hnoise−H0。
不设事后赢家选择或“模拟通过”标签，也不把相邻秒当独立样本计算显著性。

同时报告零概率的 Brier、binary log score、预测与实测零比例、完整均值、
均值 MAE、以及分开列示的中位数 MAE。中位数定义为最小满足 `F(k)>=0.5`
的非负整数。概率组固定为 `0,1,2,3–5,6–10,11–20,21–50,51+`，通过
CDF/SF 求概率，尾组不截去。不能只展示修好的零比例而隐藏尾部或总评分变差。

## 产物与访问顺序

入口为 `scripts/run_crypto_activity_aux.py`，配置为
`config/crypto_activity_aux_20261011.json`。代码、配置、测试和独立审查先提交，
再运行真实拟合。源码/配置/runtime 身份在每一阶段前后核对。

1. `fit --output ...` 只允许辅助 train reader，保存全部系数、标准化、
   alpha、固定噪声定义、优化诊断、训练评分、共同样本 hash、实际原始输入
   和特征/audit 身份。任何不完整拟合不得发布成功模型包。
2. 独立 reviewer 检查代码、数值、隔离测试以及完整训练产物，另存凭证，
   绑定整个模型文件的实际 SHA256、协议和所有源码 hash。内部内容 digest
   用于检错，不能代替这个外部模型 hash。凭证只允许打开开发诊断，
   不表示模型已经真实，也不是要求用户再次批准。
3. `export-development --models ... --review ... --access-receipt ...` 在所有
   身份、15 个模型及 UTC 时间顺序核对后记录首次市场访问授权，将此前完整性
   审查记录另存，再调用原审计程序导出开发特征。失败保留，不能覆盖或重试
   冒充第一次访问。成功凭证同时绑定批次与全部 14 个逐文件审计记录。
4. `evaluate --models ... --review ... --access-receipt ... --output ...` 只用
   冻结权重计分，不调用优化器、不重新标准化、不按开发零比例校准。再次验证
   模型/审查/访问/导出身份和全部自然日，记录样本及输入 hash。结果另存且不可覆盖。

这些是本实验入口的科学流程约束，不能阻止其他独立程序手工读取文件；
独立审查和研究记录同时约束实际操作。身份不符、失败重审留下的旧 parquet、
缺少日期或产物、读文件期间 receipt 被替换等情况必须失败退出。

## 本次能回答与不能回答的问题

该实验检验有限信息下的每秒成交计数分布是否改善，并区分分布选择和盘口
特征的增量。即便成功，仍未生成自洽价格/深度路径，未恢复新增、撤单和
逐单队列，也未验证成交成本、市场冲击、保证金/强平或 LLM 行为增量。
[逐笔执行外部诊断](crypto_execution_validation_design_20261011.md)另行实施，
不能用本实验的计数分数代替。
