# 旧回答与真人选择：200道校准题对照

**这批旧模型返回与真人的差距，比“每题都估计为各选一半”还大。** 对同一道题比较选择比例，模型实际返回与真人平均差28.33个百分点，固定各选一半与真人平均差18.17个百分点，前者多差10.16个百分点。

| 对照内容 | 实际结果 |
|---|---|
| 题目及回答范围 | 200道校准题，每题10份，共2000份旧返回 |
| 模型返回比例与真人的平均差距 | 28.33个百分点 |
| 固定各选一半与真人的平均差距 | 18.17个百分点 |
| 模型比这个简单参照多出的差距 | 10.16个百分点 |
| 两种显示顺序的比例差，先逐题取绝对值再平均 | 35.50个百分点 |
| 两种显示顺序观测比例不同的题 | 133/200道 |

沿用独立验收过的200道校准题及2000份原始回答，全部保留，包括重复返回。不重新问模型、不重挑提示、不覆盖旧指标。真人对照来自项目已冻结的Choices13k校准表，使用每道题的真人选择比例。计算方法先固定，再只读取题号和真人选择比例两列，其他列及封存测试不读取。

每道题把显示的A/B还原成原选项，计算10份返回中选原B的比例，与真人比例相减取绝对值；对200题平均。例如某题真人70%选B、模型旧返回50%选B，这题就差20个百分点。这里衡量的是比例差距，不是“答对了多少题”。每题都估计为50%的参照没有训练参数，也没有根据这批题的真人比例调整。

两种顺序各保留5份。把原选项B放前面，减去放后面，观测选择比例平均低27.70个百分点；若先取每题差异的绝对值，再平均，就是35.50个百分点。这两项都列出，避免有正有负的差异相互抵消。它们描述现有返回，不能单凭这批记录确定差异由什么造成。

总平均可能掩盖问题：若模型始终选屏幕上的第一个选项，混合两种顺序后，选原B的比例也会恰好为50%，但两种顺序下分别是0%与100%。接近真人比例，仍不足以证明学到了人的偏好。

方案、来源和显示映射先通过独立审阅，再读取这两列。44项虚构数据检查通过，独立审阅也复跑了44项；随后独立读取同样两列并逐题重算全部200题，数字吻合。工具在读取真人比例前核对了200题、2000个唯一回答机会、每题10份及5＋5顺序；读取后没有缺失、删题或删除重复返回。没有调用会打开整个数据表或其他划分的旧加载函数。

对照RP，这轮已经把“程序能跑”推进到直接检查“现有AI选择离真人多远”。目前这批原始提示（P0）的校准结果未优于固定50%的简单参照，不能据此说模型更像真人。此前已发现196/200题存在重复返回，本轮仍全数保留，不能将结果解释为独立生成的模型选择分布。顺序差也混合了显示安排、有限返回和服务复用等因素，不能直接归因于人的偏好或纯粹的位置影响。它不评价其他提示，也不代表封存测试或市场模拟已经通过。

独立审阅确定下一轮先查清一个具体问题：旧格式总把字母A放在第一项、B放在第二项，因此目前不能区分模型偏向“字母B”还是“第二项”。计划固定按题号排最前的两道题，分别改变原选项位置和A/B标签，形成每题4种格式，每种问2次，共最多16次。保留题目数值和原始指令，不发送真人选择比例；使用此前检查过的接口设置，保留与旧设置的差别。相同返回保留，不为得到不同答案补问。这只是两题上的探索性诊断，不能证明模型像真人。
