| --- | --- | --- |
| R | 重建历史盘口与逐笔标签，核验时间、单位、特征及评分 | 会读取目标窗口，须单独标识；不是预测或自主生成 |

**观测时钟与有效流的定义。** 不把“约100ms更新”当作每100ms都完整观察
市场的保证。先以 UTC 对齐的100ms网格构造观察者状态 `O(A)`：原始消息依
订阅顺序推进，只有当前原序列前缀的发布上界和撮合时间上界均严格小于 A
的状态才可用。沿用已审查的保守毫秒上界与前缀屏障；不跳过尚不可用消息。
O(A) 是服务端发布时间代理下可见的簿，不是真实客户接收状态。

对训练行 `[A,A+100ms)`，特征只能来自 O(A) 与 A 之前已经完成的成交窗口；
O(A+100ms) 和该区间成交是拟合标签，不能进入当时的输入。CSV 没有成交
消息发布时间，过去成交压力只在“成交时点可见、无额外传输延迟”的明确
理想假设下使用；这不是已测量的可交易信息。区间内同一时间戳打印保留原始
行序；半开时间区间只分配一次，不按价格或误差改分配。

这种发布时间网格使深度端点和打印所对应的撮合区间未必完全一致。必须保留
两个端点的 `cts/ts/available`、状态年龄、撮合引擎时间跨度和交易对齐诊断。
以下分解只是该时钟与可见成交假设下的有效映射，不能声称恢复了实际订单。
主型的100ms粒度固定；第一版不搜索时间偏移、粒度或“最好延迟”。

对一侧、一个绝对价格 p，令 `q0(p), q1(p)` 为两端可见量，`C(p)` 为区间
内对应主动方向、相同价格且处于共同已知价格域的公开打印数量之和。

```text
effective_remainder(p) = q1(p) - q0(p) + C(p)
effective_add(p)       = max(effective_remainder(p), 0)
effective_remove(p)    = max(-effective_remainder(p), 0)
```

这里 C 是“打印消耗了可见相应侧流动性”的代理，不保证全部来自公开簿。
剩余变化包含真实挂撤单、打印/盘口时钟错位、未观测消耗与观测误差；两端
之间同时新增再撤除的量无法识别。上述正负部分是净剩余量的最小单向分解，
不是 gross add/cancel 总量。不得直接用已有秒特征中的正负 L2 变化分别当作
挂单和撤单率，再额外扣打印成交。

**共同可见域与截断。** 用绝对价格对齐，不能把每端“第k档”相减。买盘的
共同已知域为 `p >= max(outer_bid0, outer_bid1)`；卖盘为
`p <= min(outer_ask0, outer_ask1)`，价格始终为正。在共同域内、端点没有该
价格意味着该侧可见量为零；这不允许把500档以外的量补零。价位随边缘进入
或离开、共同域之外的变化、gap/reset/snapshot跨区间均单列截断或不可分解
计数。快照是状态初始化或重置，不是一次大额补单。

所有公开打印仍保留在观察到的成交量与笔数标签中；共同域之外、无法确认
可见性或无法对齐的打印另存数量及理由，不强行分配到某档。首版不补“隐藏
队列”，不以遗漏量等于零宣称已经观测完整市场。每行保留全候选数与排除
原因；所有候选用相同的提取资格，不因某一顺序不能闭合或价格误差大而
挑选更容易模拟的训练区间。

**有限的拟合方法。** 第一版使用训练联合模板的经验抽样，而不是同时拟合
若干难以识别的强度模型。一个模板含100ms内的主动方向/数量序列、有效
添加/移除的数量及相对价位、打印与边界诊断。添加/移除价位只存相对该侧
区间起始最优价的整数偏移；不存用于生成的未来绝对价格、收益或终点盘口。
打印未来价格保留在提取证据中，但不得放入生成模板接口。

M0 从同一个合格训练池均匀抽取整行联合模板，保留该行内部侧别与数量的
关联。M1 只改变选池规则：固定18个状态格，分别为起始 L1 量失衡三格
`[-1,-1/3)、[-1/3,1/3]、(1/3,1]`、价差低/高两格，以及过去完整1秒
打印 BTC 数量失衡三格（`(buy_qty-sell_qty)/(buy_qty+sell_qty)`，使用同一组
分界；无成交记0）。价差分界取训练行中位数。
状态量由生成簿与生成打印重算；不能用真实目标路径补回。池少于32行时
固定回退 M0 池，记录回退频次；不为每格搜索不同模型或调门槛。所有参数、
模板行身份和抽样算法须在真实生成前冻结。这些分箱是原型假设，不是依据
未见结果选出的最优划分。

第一版每步独立抽模板，允许 M1 通过自身状态和过去压力产生反馈；不声称
已经保留跨区间的订单拆分、自激、日内制度或长记忆。若这一简单模型失败，
保留结果，再另登记带长记忆的候选；不把新的模型追补到本版本中。

**避免重复消费交易。** 模拟器每步开始将模板的相对价格映射到自身当前
最优价，一步内固定这些拟议目标价格。新增是合成限价单，移除只取消当前
自己簿上存在的数量。主动方向/数量作为合成 IOC 意图，经自己的撮合器
逐档成交，实际价格和笔数从这些匹配生成。撮合已经扣去的量不再从深度
减第二次；生成后不把 q1 真值写回、不把差异称作需要“纠错”的负量。

公开每笔可能是整张主动单的一次部分执行，不能据其 timestamp、方向或
相邻 ID 恢复 parent order。将每笔大小作为一个合成微型 IOC 意图，只是
首版的有效表示。一个意图可能产生多个价格的执行，或因深度不足不成交，
因此“拟议意图数”不会自动等于历史打印数。必须分别输出意图数与实际
执行打印数；评分使用实际生成的打印。为避免合成挂单碎片数任意改变打印
数，首版明确采用“同一合成意图、同价执行合并为一次输出打印”的模型
发布规则；不合并原始历史打印，也不称该规则已验证为2024年的交易所制度。

**两种预定的区间顺序假设。** 同一模板、同一起始簿、同一个随机流分别运行：

1. `S1`：移除 → 添加 → 主动意图。
2. `S2`：主动意图 → 移除 → 添加。

净被动价格事件的编码与执行顺序固定为买侧价位从高到低、再卖侧从低到高；
它们已经由端点聚合，不能保留未识别的原始订单顺序。主动意图保留打印
源行顺序，价格冲突不按效果重新排序。共同域内的净分解
在理想单价余额上可能可行，但不保证跨两侧、按真实撮合后的路径仍可闭合。
两种实施都通过数量有界取消、纯被动限价检查和 IOC 余量处理保持合法：
撤量超过当前可撤量时只撤存在部分，剩余作为未实施移除；拟议被动价格会
交叉对侧时拒绝该添加并记原因，不把它强行投射到更好价格；IOC 超过当前
簿时只成交可见模型量，余量取消。价位非正、风险不足也明确拒绝。大量
裁剪/拒绝是模型适用性失败的信号，不是被修复后可以隐去的记录。不得以
哪个假设得分较好选为“真实顺序”；结论依赖单一种顺序时不能判机制稳健。

一个构造反例说明成交后补挂不能由“新增总在成交前”覆盖：初始 bid 为
1 BTC @99，asks 为1 BTC @100和1 BTC @101；区间内有主动买入1 BTC @100
的打印，终点另出现1 BTC @100.5的 bid，原99 bid仍在。对100 ask，
`Δq=-1, C=1`，有效剩余为0；对100.5 bid，有效添加为1。若先添加，100.5
bid会交叉尚在的100 ask，被本原型的纯被动门控拒绝；若先成交消耗100 ask，
剩下最优ask101，随后100.5 bid可合法加入。两个端点及打印本身不能决定
真正采用了哪条区间路径。S1/S2检验这种时间顺序的不确定性，不是恢复
历史真值，也不能因S2更容易解释这个例子就只运行S2。

**自主价格与深层边界。** 初始化仅拷贝起点已可用盘口；历史对象保持只读。
之后禁止读取该窗口未来 raw、特征或真实价格。历史500档只提供有限起始
模型簿，生成的新增限价单可创建新的绝对价位，引用的是模型当前最优价。
既有挂单保留其绝对价格，不能跟随抽出的未来真实收益平移整本。买卖吃掉
最优量、撤掉最优档或在价差内新增时，模型的中间价及成交价才相应改变。

初版不设置真实价格锚、不重置空簿、不从真实下一张盘口补边缘、不无限量
刷新 LP。模型的订单簿可保存全部由自己生成的订单；评分的观测视图只取
每侧500档，并报告5bps覆盖与深层截断。起始未观测流动性仍是未识别边界，
并不因模拟簿在程序内完整可见而成为历史全市场深度。空边、非正报价、
无法构造指定双侧指标等须保留全部种子和窗口的失败分母。

**复用现有撮合与账户的界限。**

| 现有部件 | 可复用部分 | 原型需新增的适配 |
| --- | --- | --- |
| `BybitBook` | 精确整数重建与只读起始状态提取 | 将价位/量拷入独立合成簿；不向历史对象提交合成变化 |
| `OrderBook` / `MatchingEngine` | 限价、价格/时间优先、逐档匹配、禁止自成交 | 模型事件时钟、合成订单ID、部分数量取消、IOC终态与打印发布规则；初始每档的合成排队不代表真实队列 |
| `Exchange` / `Portfolio` | 现货资源检查与结算可作另一个工程对照 | 当前数量是整数股份、卖出不能超过持仓、现金按价格×股份结算；不能直接当 USDT 永续交易所 |
| `LinearPerpetualAccount` | Decimal有符号头寸、部分成交、平仓/反手、费用、唯一事件ID | 完整订单承认、未成交挂单风险预留、跨账户原子结算、模型 mark 时钟；历史MMR/清算/ADL仍缺失 |

数量存储单位保持 `0.001 BTC`，价格保持 `0.01 USDT/BTC`。这两个是精确
存储尺度，不是已确认的历史最低 lot/tick。若复用现货 Exchange 作机械
对照，价格必须转换为每个数量单位的 USDT，即 `price_USDT_per_BTC/1000`；
否则其现金结算差1000倍，且账户仍只能称作现货。永续原型优先复用
MatchingEngine 与 OrderBook，在结算回调中用 `Decimal(q_units)/1000`
和 `Decimal(p_units)/100` 调用独立永续账户，完全绕开现货 `_execute`。

需要两个背景挂单账户与两个主动账户，避免同一账户吃自己订单；初始挂单
归属是人为假设，不是恢复出的投资者。最小工程资源对照采用有限初始资金：
每账户现金设为起始双侧可见挂单总名义 G，杠杆上限1，费用及最低开仓名义
均设0；四账户总资金固定为4G，禁止中途充值。该设置只提供明确、相同的
保守资源约束，不是历史财富或费率估计。新的DAY挂单预留全部未成交数量的
保守风险；主动IOC按完整可见成交计划的全部partial fills、双方账户和剩余
挂单风险原子验证，不为即刻取消的不可见余量继续预留。取消释放未成交预留。资金
配置、拒绝率须随结果公开，不能据留出得分增资直到通过。

账户与合成簿均可在本地副本上预演一次完整 IOC；只有所有部分执行、双方
费用、头寸与剩余挂单预留都通过，才原子提交副本。不得先让撮合器扣量，
再遇到账户风险失败而留下半次结算。模型 mark 暂用自己的双侧中间价并
明确标为代理，不能当已验证的交易所指数/mark。窗口必须独立核对已归档的
原始资金费 settlement 时间、时区及起止时钟边界；目标周 BTCUSDT 已核对
的时间为00/08/16 UTC，不能把每个整点都视为资金费，也不能推广到所有
场所或时期。固定每小时第10—15分钟的窗口若确实不跨这些时点，最多避免
该短窗口内的资金费结算；不说明其他分钟的 mark/index、保证金或清算路径
无关或已验证。后续仍需真实可用时点、费率、标记价与清算制度适配；本
原型不会凭现有账户测试宣布这些部分已完成。

标签；共同域量与截断量；全部资格原因；训练输入hash与提取源码hash。
生成模板的窄接口剔除真实未来价格及终点簿，完整证据单独保存。所有真实
输入消费者仍在读文件前拒绝 development/event_test；本次计划不开放它们。
提取器逐日流式运行，只持有前后状态和当前100ms打印缓冲；增减数组保存
稀疏价位，不物化全天全部500档副本。模板池的行索引与内容hash一并冻结，
生成器可以读取这个已拟合训练产物，但不能通过模板索引访问评价期档案。

完整训练计划沿用11月1—3日、每小时第10分钟开始的五分钟窗口与20个固定
种子。冒烟只能用第一项既定窗口 `2024-11-01 00:10—00:15 UTC`，不能按
价格或运行误差改选。M0/M1 以及两种顺序共享起始状态、窗口、候选分母，
随机种子只作 Monte Carlo 重复。P 的整段块仅取合格训练连续窗口，不拼
跨gap的路径。R 标签访问单独记录；生成器一次初始化后只收到自己的事件。
拟合与评分使用同一训练期时，分数明确属于训练内诊断；即使数值改善，也
不能当作留出验证或选择后续事件检验的通过阈值。

额外信息延迟0/1/5秒仍是已有设计的必需敏感性。拟合时标签保持同一零延迟
发布时间代理网格，M1分格输入改为对应时点已可用的滞后状态/过去压力；
模拟时仅从自己事件历史构造延迟输入。各延迟的环境从同一份已批准起始
可见簿初始化，过去上下文只取窗口开始之前，不能先重放目标窗口。这个
环境初始化是已知起始状态的条件实验，不证明真实延迟交易者拥有同时刻
完整盘口。0延迟工程原型可以先实现；尚未实现全部敏感性时不能报告机制
稳健或完整设计完成。

**评分及失败记录。** 主向量沿用未来60秒的七个量：中间价收益bps、实际
成交BTC量、实际发布打印数、平均价差bps、平均买侧5bps深度、平均卖侧5bps
深度、买卖成交数量失衡。后六项中的量/笔数/价差/双侧深度先做 `log1p`
变换，失衡保持原值；每维用完整训练标签标准差固定尺度，零标准差使
拟合失败，不事后删除维度。每个五分钟连续生成一次，评分其五个不重叠
60秒块并给整个窗口等权均值；另报1秒路径与全五分钟的诊断。

对20条生成路径 z 和同窗真实 y，用固定尺度后的 fair energy score：

```text
ES = mean_k ||z_k - y||
     - sum_{k != l} ||z_k - z_l|| / (2*K*(K-1)),  K=20
```

M1 与 M0 配对比较同窗口同顺序同延迟主分数，先按日列值，再对完整日等权；
M1 的价格子分数另与 P 比较。P 不补造盘口参与完整七维比较，R 的回放
吻合不作为生成分数胜出。各维90%区间覆盖、零收益、空边、5bps截断、绝对
收益持续性、方向持续性与当前状态—后续价格联合关系均单列，防止联合
均分掩盖明显失真。记录所有资金拒绝、被动交叉拒绝、未实施撤量、IOC余量
及合成打印/意图差异；固定分母不能因结果难看而缩小。

真实窗口需满足预定完整同segment覆盖。模拟路径缺双侧价格或任一主量
无法定义时不填零、不承接上一中间价、不仅删除坏种子。该窗口主分数标记
不可完整评价，保留全部路径的失败率；候选覆盖不完整时只给有效窗口的
描述，不能据此宣布整体优于对照或通过。首版不新造一个可调“失败罚分”。
没有与研究用途对应的冻结实质改善容差时，本轮只作开发诊断，不把训练
日分块 bootstrap 或20种子充作新交易日的独立证据。

**进入真实生成前的有限验收清单。**

1. 构造 L2/打印例子验证净剩余分解、同绝对价格对齐、边缘截断与一次分配；
   包括 gross新增再撤销不可恢复的反例，不能只测顺利闭合例子。
2. 固定相同过去与随机种子，任意修改未来历史价格/深度/打印都不改变生成；
   单测模拟入口没有标签/路径读取能力，初始历史对象hash前后相同。
3. 两种顺序都保持量非负、唯一事件ID、合法IOC余量、无自成交；撤量与成交
   不重复，交叉被动请求明确拒绝；空边与风险不足完整记录。
4. 验证价/量/现金尺度、双账户原子结算、挂单预留及取消释放；部分执行
   风险失败时簿和全部账户均不变。合成打印合并不改变成交量和账目。
5. 验证拟合只读训练、延迟输入因果、全部模板/参数/源码hash冻结、失败
   manifest不可消费；评分程序只在生成完成后独立读批准目标。
6. 独立agent审查后先运行既定训练冒烟，所有方法与顺序一同运行并报告
   分母。只有通过上述工程检查，才考虑完整训练窗口；不能由冒烟结果
   选胜者后省略另一个顺序或调整资源。开发/事件开放需要后续明确冻结流程。
