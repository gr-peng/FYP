# 双事件模拟：首轮结果（阶段报告）

目前系统能做受控对照，但还没有复现这两次真实市场走势。盘口数据不是唯一问题：这轮同时发现了交易动机不足、报价精度不一致和持仓比例理解错误。

## 现实基准

第一场景采用用户确认的2026年6—7月这次Meta算力消息，主时间为7月1日可核验报道。6月30日至7月31日，SOXX跌21.20%、MU跌28.70%，NVDA却涨0.33%。不能只盯NVDA代表板块，也不能把一个月全部跌幅归因于一条消息。

第二场景中，BTC从11月5日UTC零点至AP正式确认胜选前已涨8.66%，确认后24小时再涨1.44%。新闻是逐步出现的，不能把全部涨幅放到正式确认之后。

完整数据、来源和窗口说明见[现实行情报告](../outputs/two_event_20261004_v1/empirical/REPORT.md)。

## 实验结果

冻结代码`4e05cf5`，配置`config/two_event_market_pilot_v4.json`。每格6个代理、1个种子，MU跑6月30日至7月2日，BTC跑11月5日至7日。两种代理设定、两种流动性、新闻/无新闻构成每资产8格，共432次真实模型决策。

|---|---|---:|---:|---:|---:|
| MU，普通 | 无 | 0.00% | 0.00% | 0.00 | 0 |
| MU，普通 | 有限 | 0.00% | 0.00% | 0.00 | 0 |
| MU，私人配置目标 | 无 | 0.00% | 0.00% | 0.00 | 0 |
| MU，私人配置目标 | 有限 | 0.00% | 0.00% | 0.00 | 0 |
| BTC，普通 | 无 | 0.00% | 0.00% | 0.00 | 0 |

| BTC，私人配置目标 | 有限 | +0.80% | +0.48% | +0.32 | 9 |

相同日期的实际收益是MU -14.82%、BTC +11.80%。日线真实收盘覆盖全天，而模型仅在每日开盘和登记新闻时刻决策，两者时间分辨率也不同。不能把这次短窗口模拟与现实一个月收益直接比。

MU的192次决策实际为14次买入、178次观望、0次卖出，最终0成交。早期进度消息误写成“全部观望”，这里明确更正。11笔买单报1147.57美元，模拟最低卖价为1147.570589，仅差0.000589美元就没有成交。这暴露了模拟报价网格与常见按分报价不一致的问题；另3笔报价更低。零成交不能全部解释为没有交易意愿。

BTC普通代理在有新闻且有有限做市时产生了5笔成交，但对手方全部是背景做市商。私人目标组虽然涨了0.80%，无新闻时也涨了0.48%，所以显式新闻的增量只有0.32个百分点。不能把全部模拟涨幅当作新闻效应，更不能等同于真实事件的因果效应。

还发现数值理解错误：MU代理A003实际资产权重约49.62%、目标20%，却在解释中声称已经接近目标。下一轮将由代码计算权重和差额，并修复报价单位和网格。原结果保留，不在旧数据上改价补成交。

## 证据是否可靠

- 432次决策均与原始JSON逐条核对，96对消息前观察和决策完全一致。0拒单、0隐藏HOLD降级；资金和份额守恒。规则负对照的新闻/无新闻路径一致。
- 正式V4共336次新成功调用、96次缓存，输入293,234/输出21,181 token。此前V1因思考模式不一致停止，V2/V3探针失败，均保留；V4本地模板开关通过8/8探针及正式响应检查。失败和取消调用不混入主结果。
- 做市资金和库存有限；价差、深度、私人配置目标都是明确假设，尚未由真实LOB或真人数据估计。模型可能记得2024大选；无新闻组不等于完全不知情。6人1种子只够发现问题，不作显著性结论。

## 同时推进的真人行为验证

在已经开放的51场训练实验、63,143个主动下单时点上，加入跨轮个人历史后，统计模型五折场次交叉验证的Brier误差从0.22750降至0.21571。历史只来自当时已经结束的轮次；跨重复实验保留记忆，但不混用重置后的账户。

这仍是训练内探索，不是独立验证。数据只说明“已决定下单时买还是卖”，不能直接推算观望概率。开发集和测试集仍未打开，也没有把这些概率硬塞进本轮股票/币市场。

下一步先验证交易精度、单位和数值事实修正，再做金融行为的独立评价、流动性敏感性和更长窗口的多种子实验。最终通俗实验报告尚未完成。
