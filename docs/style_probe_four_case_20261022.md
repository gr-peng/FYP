# 四条策略占比比较已完成（2026-10-22）

这轮取得了一个值得继续验证的现象：**原来采用技术策略的代理，在技术策略占多数时保持原策略，在基本面策略占多数时改选基本面。** 另一位原来采用基本面策略的代理，两次都保持基本面。四条回答已收齐，但每个问题只问过一次，还不能确定差异是否稳定。

技术策略主要看价格走势，基本面策略主要比较价格与系统给出的估值。这里改变的是“群体中多少代理使用哪种策略”；同一组里的账户、收益、经历、行情和其他提示都相同。群体占比是为了比较而设置的假设，不冒充真实发生过的市场状态。

| 原来的策略 | 自己的策略占 80% 时 | 自己的策略占 20% 时 |
|---|---|---|
| 技术策略 | 保持技术策略 | 改选基本面策略 |
| 基本面策略 | 保持基本面策略 | 保持基本面策略 |

两组里的占比反转都只改两个数字。两位代理各自的账户和经历不同，因此不能进一步说“技术型一定比基本面型更容易跟风”。模型给出的理由也只是回答内容，不能当作其真正决策过程的证明。

## 对照 RP，现在推进了什么

RP 要研究的是：AI 是否表现出与人相似的决策变化，这些变化能否进一步形成更真实的市场。这次只推进了其中很小的一步：同一个假设投资者面对不同群体占比时，系统已经能完整收回、核对并比较回答。

| RP 中的问题 | 本轮进展 | 仍然缺什么 |
|---|---|---|
| 群体信息会不会伴随策略变化 | 两个固定情境中，一组变了、一组没变 | 同样问题的重复结果、更多事先选定的情境 |
| AI 的变化是否像真人 | 本轮没有新增真人比较 | 与同类决策相匹配的真人行为依据 |
| 行为变化能否带来更真实的市场 | 本轮没有运行市场 | 先确认行为，再检验交易与价格结果 |

不能把“一组变了”写成“已证明 AI 会跟风”，也不能把“另一组没变”写成“群体占比没有作用”。模型回答本身可能有波动，单次差异还不能排除这种可能。

## 系统这次具体改了什么

补上了原先计划的技术策略两条检查，并增加了四条结果的统一汇总。汇总会重新读取两阶段原始请求和回答，核对它们使用的是同一套材料；重复记录、版本混合、测试样例混入实际记录都会被拒绝。少一条回答时，整组明确显示无法比较。

新增 10 项检查，相关检查累计 **172 项通过**。旧基本面结果用新代码重算，与旧汇总逐字节一致。同一个独立子 agent 在执行前检查方案，执行后直接核对原始日志并独立重算，结论为通过，无必须修复项。

## 实际调用与证据范围

本轮新增两次请求，均成功、非缓存、无重试。连同之前一次失败和两次基本面成功请求，累计 **5/5 次**，没有剩余额度。你已明确同意将上限从四次增加到五次；原先的失败记录完整保留，没有算作有效行为结果。

有效的四条新版回答合计使用接口报告的 5,154 输入、239 输出 token，报告的思考 token 均为 0；这只能说明未观察到返回的思考内容。根 agent 通过实际执行会话观察到请求结束，离线检查工具本身不会把本地日志标记为外部认证。

旧实验文件、已批准的 49 个候选文件和旧交付 ZIP 均保留。SCIT 批量优化继续暂停；本轮没有打开保留的真人测试数据。

## 下一轮先解决什么

先检查重复性：同样的输入多次回答会不会自己变化，以及反转群体占比后是否持续出现方向一致的差异。按独立审查建议，已离线准备原四种输入各重复四次、共 16 条待发材料；每种输入在第一到第四个位置各出现一次，每一对的先后顺序也各安排两次。提示与账户保持不变，现有四条不混入新复测的主要统计。

失败不重试，首个不合格即停；所有预定机会都保留，没有问到的明确列为缺失，不因结果不理想追加或改提示。这份计划尚未执行，也不是可直接启动的执行包；还需完成专用工具、独立验收，并另获新增最多 16 次请求的明确授权。四次重复仍只适合做小规模稳定性检查。当前的四条小检查已完成，RP 的正式行为研究仍未完成。
