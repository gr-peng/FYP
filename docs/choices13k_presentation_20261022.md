# 两题检查：模型偏字母，还是偏位置

**16次真实模型请求已完成，两个题目的变化不一样。** 第一题显示方式变化时，同一方案被选择的次数不同；第二题大多数返回选择同一原方案。还有两组相同提问，前后给了相反答案。因此目前无法用一个统一的“总选字母B”或“总选第二项”规则解释这些返回。

上一轮200题的旧返回与真人比例平均差28.33个百分点，比固定各选一半的18.17个百分点更大。两种显示顺序也有较大差异；但旧格式总把字母A放第一、B放第二，无法区分模型偏字母还是偏位置。

本轮固定按题号排序最前的两题166、211，不按真人误差挑题。每题把原选项前后位置和标题A/B分别交换，形成四种格式，每种问两次，最多16次。题目数值、概率、隐藏概率的文字和原始指令都不改，不发送真人选择比例。使用此前检查过的模式及缓存设置，并保留与旧版本的差别；这不保证接口一定执行了这些设置。

比较位置时固定同一原选项的字母，比较字母时固定它的位置。虚构检查覆盖了“始终选原B”“始终选字母B”“始终选第一项”和“始终选第二项”，避免计算时又把两者混在一起。

| 实际观察 | 结果 |
|---|---|
| 第一题166，同一原方案B放后面 | 4次中4次选它 |
| 第一题166，同一原方案B放前面 | 4次中1次选它 |
| 第二题211，是否仍选同一原方案A | 8次中7次选它 |
| 相同提问两次回答不同的组合 | 8组中2组 |
| 成功收到合格回答 | 16/16次 |

这里的“原方案”指固定的那套收益和概率，交换标题字母时内容不变。完整四格结果也保留，不能只看合并后的次数：第一题在原B放前面时，标成A的两次都没选它，标成B的两次有一次选它；第二题也只有“原B放前面且标B”这一格有一次选原B。每格只有两份收到的回答，这些小范围差异不能当成一般规律。

16条输入及顺序在发送前固定并通过独立审阅。预检只用虚构接口；真实第一条已计入16次额度。逐条发送，没有重试、修复、补问或缺失。16条都有不同的回答编号、时间和正文组合，未发现同组合重复；这仍不能证明独立生成，也不能证明接口执行了缓存设置。

本地45项检查和独立45项检查通过。审查中修复了一个本轮工具漏洞：外层返回出现重复字段时，原解析器会悄悄合并，现在严格拒绝并保留异常原文。新增虚构反例确认首条、中间或最后一条异常都会停止，未因此增加真实请求。实际16条已由独立子agent逐条核对，并重新计算全部四格结果和比较，验收通过。

对照RP，本轮查清了原先把字母和位置绑在一起的设计限制，并记录到两题不同的选择变化和同输入波动。它尚未证明模型学到了人的风险偏好，也没有改进或重算上一轮200题的真人对照。新设置下的这两题结果不能追认旧实验的显示差异都由某一种因素造成。

独立审阅确定下一轮先做一个通用的公平比较工具，新增模型请求计划为0次：不同提示方法必须使用同样的题目、四种显示格式和同样次数，再逐题比较选择与真人比例的差距。缺少某格回答时，相关结果保留未知，不能偷偷删题再算平均。先用虚构数据演示“真人参考”和“打乱参考”两个方法的完整比较，不加载新的真人例子，不把虚构演示当成方法有效的证据。这会把本轮发现转成以后可以直接使用的研究能力，避免一直重复问这两题。

累计已用75/100次，剩25次。本轮没有读取真人比例列或封存测试，没有发送真人比例，没有启动新的市场模拟。
