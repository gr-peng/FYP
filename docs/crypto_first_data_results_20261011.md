# 加密市场：真实盘口接入后的第一轮证据

2026-10-11。结论是**已取得并完成同场所历史盘口与逐笔成交的全档案审计，已量化训练/开发市场特征；尚未证明模拟能真实生成市场。** 新目标继续进行。

用户已确认此前讨论的Meta事件就是2026年6—7月同一次报道；这不改变当前先做加密市场的主线。

已归档2024年11月1—7日Bybit BTCUSDT线性USDT永续合约的7份500档L2快照/增量文件、7份逐笔成交文件，总大小2,632,504,549字节。14份文件在`f7f0d2e`上完成hash、ZIP/GZIP CRC、schema与序列/时间检查；7份LOB结构检查通过，7份成交档案均valid。`u`连续是保守诊断，档案未提供独立交易所checksum，不能据此证明源端没有隐性缺失。该市场是中心化交易所永续，不是链上、也不是之前的Binance现货。

训练为11月1—3日，开发为11月4日。四天各导出86,397个完整且满足可用时刻约束的盘口秒样本。11月5—7日只完成完整性检查，未导出特征、未计算市场分布或模型分数。真人金融最终16场仍封存。先前来源检查产生的整周资金费范围摘要已被看到，此事实保留披露，不能称所有测试期数值完全未见。

初次代码把日文件尾部跨入次日的18/19/19条消息误判为错误；原审计和特征保存在`initial_ec620a4_audit/`。修正后只在格式审计容许日界前后60秒，特征仍要求本日桶且可用时间严格早于次日00:00。特征时间同时考虑桶结束、已用segment前缀最晚发布和确认桶结束的消息，失效段不填补。重审前会原子撤销旧成功manifest，失败或中断后不能误读旧Parquet；消费者重验原始文件和输出hash。

以下是真实数据的描述统计，**不是模拟成绩**。盘口按保留的完整秒等权，收益要求连续同segment，分钟收益为不重叠的60秒对数中价收益；深度指可见前5个价格档位。成交数均值按盘口与成交档案共同覆盖秒计算：11月1、4日为86,396秒，另两日为86,397秒；不是按86400秒全日直接平均。1 bps = 0.01%。

这给下一步提供了具体约束。旧有限LP使用20bps半价差参数，即理想化约40bps双边价差；新目标场所训练期价差中位数约0.014—0.015bps。两者相差约2,738—2,782倍，但前者是旧现货实验参数，实际报价还受舍入、库存和其他代理影响，因此这不是同场所实测误差或公平模型比分。它说明不能把旧背景流动性参数直接当成新的永续市场校准结果。

成交活动也不是固定节奏：三天训练均值约7—26笔/秒，秒成交笔数的样本方差/均值约195—387。成交拆分、时段变化和活动聚集均可能造成这一现象，不能只凭该比值宣称发现自激机制。简单恒定强度Poisson模型需要接受这些数据的检验，不能默认可信。

500档并不等于完整市场深度。四天保留样本的双侧±5bps范围均被覆盖；±10bps仅约85.3%—90.8%被覆盖，±25bps覆盖为0。25bps深度不能拿截断和当成真实总量；已重建的可见报价能支持有限深度成本诊断，却不能给超范围订单无依据地补成交。

时间与解释同样重要。盘口失衡与之后价格的描述关系已导出，但这里的目标先等待可用时刻之后的合格观察秒，再计算1秒或60秒收益；目标起点平均再晚约1.89—1.90秒。成交CSV只有撮合时点，桶结束是理想可用时间下界；盘口TS是服务器发布，均不是实测客户端接收时间。相关性不代表可交易收益、因果冲击或模拟成功。

独立审查通过了下载、重建、失败状态授权链及永续账本的工程复核。基础全项目245项测试通过，新增profile21项语义测试通过；审查者另以独立逐行算法核对180组随机时钟/缺秒场景共2,623对目标，结果一致。账本表示盈亏、手续费、资金费与实验敞口约束；历史风险档位、保证金预留、清算/ADL仍不完整，也尚未构成集成交易环境的外部验证。

目前分层进度如下：

| 层次 | 已有证据 | 尚缺的证据 |
|---|---|---|
| 真实观测重建 | 完整归档、CRC/结构检查、保守时钟、训练/开发profile | 独立源端checksum、逐单队列和更广时段 |
| 执行效果 | 可见盘口逐档扫单与独立永续账本 | 整单提交/成交/延迟真值，被动排队及反事实冲击验证 |
| 内生市场 | 旧CDA机制和新真实数据约束 | 新机制自主生成盘口/成交的留出成绩 |
| LLM/真人行为增益 | 旧实验负结果被保留 | 同一已验证市场背景上的新增外部支持 |

下一项实验先检验当前盘口能否在时段和已知成交活动基线之外改善下一完整秒的成交笔数预测；这是可观测条件机制的开发诊断。这项结果用于筛选成交强度模型中的状态依赖，再进入不读取未来真实行情的短期自主模拟；该项若没有增益，也不能推出LOB对排队、成交成本或其他状态转移没有价值。预定延迟敏感性、共同样本、训练期拟合和独立复核均须保留。三天训练不能可靠定义普遍真实性门槛，因此另预声明更早的完整自然周补充样本；不得查看行情后挑日期，原大选最终检验保持封存。
