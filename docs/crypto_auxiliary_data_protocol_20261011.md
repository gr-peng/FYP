# 加密市场辅助数据预注册：连续两自然周

日期：2026-10-11。状态：下载前计划。此文和配置须先由主任务提交，再启动原始行情下载或查看所选日期的市场profile。本次子任务只登记配置、协议及官方档案目录元数据，不发起行情档案下载、不解压或解析行情，也不自行commit。

独立审查指出：原研究只有三个训练日，不足以可靠估计稳定的自然波动门槛。增加样本的目的，是观察更多完整交易日的自然差异，并设置另一个按时间向后的开发周；取得两周数据也不自动解决独立性、市场制度覆盖或小样本问题。

## 信息顺序与允许的结论

辅助样本是查看其行情前新增的回顾性历史样本，并非2024年当时开展的前瞻试验，也不能回写成研究者此前从未看过任何市场数据。已有11月数据检查、代码修复和方法选择的历史必须保留。

辅助实验的参数、标准化统计、分层边界、过程拟合、自然差异参考值及候选选择，只能从辅助train的10月14—20日估计。运行10月21—27日开发评价前，冻结该版本代码、指标、参数与输出解释。每天均按完整UTC日期报告覆盖及质量，不使用辅助development计算训练归一化量或调阈值。

不能先用11月1—3日拟合参数，再把10月21—27日评价称作严格向前检验。若需要比较原11月拟合模型在10月的表现，必须另标为向历史样本的迁移诊断，不能与“10月辅助train→10月辅助development”的结果合并。任何联合拟合版本都要逐一列出拟合日期，不能借用辅助开发周的独立留出称谓。

若根据开发周结果修改模型，该周从此属于已使用的开发信息；保存修改前后版本和选择过程，不再次声称其为新版本的未见验证。原11月5—7日仍保留到最终模型和评价规则冻结之后，不用于补充数据选择、参数、阈值或停止规则。

基本自然变动单位是完整交易日；日内可用预先定义的非重叠时间块做描述，但不能把大量分钟或5分钟块当作独立新交易日来制造窄置信区间。七个训练日仍只覆盖一个自然周，另一个开发周也不是多个独立市场制度。暂不预设“超过某个由小样本算出的95%区间即模拟失败/成功”；是否设等价容差、依据是什么，须在最终检验前另行明确并记录。
