## 已完成的真实计算与独立复算

39,333 笔实际 print 各比较五个额外信息延迟，共保存 196,665 行。
真实 side/size 是事后给定的条件，代理使用严格更早且已生成的盘口；
真实 price 不参与扫单。每笔独立只读扫单，不永久扣减历史簿。
公开 print 不等于整张主动订单；同一订单可能产生多笔 print。

独立 agent 核对了全部来源/产物 hash、196,549 个合格行的有理数误差、

## 盘口深度提供了什么增量

0 ms 下只有 2,733/39,311 笔超过当时对手 L1 数量；其余多数小 print 的
sweep 与 L1 报价相同。因此总体 MAE 改善约 0.00846 bps，不能充分检验
跨档价格模型。跨 L1 的同样本 sweep/L1 MAE 为 **1.053894/1.175561 bps**，
成对差为 −0.121666 bps，P99 为 **4.075971/4.230197 bps**。

五延迟共同跨 L1 仅有 1,008 笔。各延迟的跨 L1 子集从 1,561 到 2,733 笔
变化，不能直接混比。以下是在固定 1,008 笔上的结果：

或撮合到达延迟。原始毫秒时间的保守上界也不证明两路时钟完全同步。
