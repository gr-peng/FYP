# 下一次怎样分清AI是在追收益，还是跟多数

**这轮已经做出16份账目一致的假设材料，用来分别检查原策略标签、参考估值、策略收益信息和群体多数。没有新增模型回答，所以还没有新的行为结论。**

上轮发现107次策略切换中，106次都是技术转基本面。本轮向前推进的是：把能区分几种解释的输入真正做出来，避免把不同账户直接比较后就叫作“跟风”或“惯性”。

## 原材料哪里混在一起

原来两位模拟代理看到同样的行情和参考价，但一位持100股、另一位空仓；亏损、替代收益、回撤和交易经历都不同。它们都看到“另一策略过去表现更好”。因此，跨账户差异不能直接说明原策略或收益信息造成了什么。

每个账户内部那一对原材料，确实只改了群体策略占比，可以描述该账户在那个特定情境下对多数信息的反应。但这不足以解释全部540次旧选择的方向。

## 这次做出的对照

新材料全部标为假设，不冒充真实市场数据。使用相同的持仓和价格经历：现金10000、100股，价格从100降到95；始终不交易，最终权益19500，亏损2.5%。在此基础上排列四项信息的全部二选一组合：

| 信息 | 两种情况 |
|---|---|
| 原策略标签 | 基本面或技术；历史标签同时对应 |
| 系统参考估值 | 95或105，当前价格固定95 |
| 策略过去的收益信息 | 基本面较好或技术较好 |
| 群体多数 | 另外100位代理中，基本面80人或技术80人 |

16份材料可以配成32对比较，每一对其余三项相同。32对共享这16份材料，不能当作32次独立实验。

独立子agent指出，如果同时展示基准的收益和仓位，可能把追收益与关注风险混在一起。现在提示只展示假设收益；用于核对算术的仓位留在离线记录里。改变原策略标签时，两种具名策略的收益排名保持不变。

这组材料能检查模型是否对指定信息有反应。策略标签的影响不能直接叫真实习惯，假设基准收益也不是某位代理换策略后一定能赚到的收益。所有场景都亏2.5%，因此没有检验盈利与亏损的差异。

## 检查和独立审查

修复后的相关检查共77项通过，其中40项覆盖新增设计。独立子agent另行运行40项，并独立复算16份材料的账本、基准和32对字段变化，验收通过。

它还发现并推动修复了两类漏检：重复JSON字段会掩盖冲突、伪装成嵌套路径的额外字段可能混过检查。对应反例现在均被拒绝。实际16份提示原本没有这些问题，修复前后提示及对照内容没有改变。

## 对照RP，下一步做什么

关于AI如何改变策略，我们从“统计它做了什么”推进到“准备可比较的条件”。**还没有证明行为像真人，也没有新增市场价格或群体反馈的验证。** 这一步服务于RP里的策略选择问题，不能算市场整体模拟已经完成。

下一轮先离线准备固定的4个场景：原策略标签和参考估值保持相同，只交叉改变收益排名与群体多数。两种信息同向、冲突的情况都保留，提前写清如何处理全选同一策略、缺回答或无效回答。其余12份材料明确不安排执行；这4格也不能代替全部16格或四类因素的验证。

本轮新增模型请求为0；之前授权的21次已用完。实际运行前仍需新的具体额度及响应复用处理方案。没有打开保留的真人测试数据，没有恢复SCIT优化，也没有修改旧实验结果。
